# SO14 — Indicadores de economía, medios de vida y bienestar

Sitio estático de trabajo sobre los indicadores del Tambopata landscape.

**Página publicada:** https://rmcondor.github.io/so14-indicators/

**Repositorio:** https://github.com/rmcondor/so14-indicators

Incluye tres pestañas: **Codebook**, **Indicators** y **Analysis**. El dashboard utiliza exclusivamente datos simulados para ilustrar posibles análisis. Las definiciones pendientes están identificadas dentro del sitio.

## Publicación

Publicar con GitHub Pages desde la rama `main`, carpeta `/(root)`. `index.html` es el punto de entrada y `.nojekyll` permite servir el HTML sin procesarlo con Jekyll. No requiere dependencias ni compilación.

La publicación contiene únicamente esta página y los archivos de configuración del sitio. Las preguntas Q&A, los trackers, los documentos originales y los archivos de datos se mantienen fuera de este repositorio.

## Actualización

Copiar la versión actualizada de `outputs/SO14_indicator_review.html` sobre `index.html`, comprobar las tres pestañas y enviar el cambio a `main`. GitHub Pages publicará la actualización automáticamente.

Las referencias apuntan a fuentes externas públicas; el sitio no depende de archivos de la computadora del autor.
